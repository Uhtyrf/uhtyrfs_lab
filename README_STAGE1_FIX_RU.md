# Uhtyrf's Lab — исправление характеристик (этап 1)

Изменения внесены в копию проекта на основе аудита. Исходный архив не изменялся.

## Исправлено

- Добавлен единый справочник `Ability`: короткий ключ (`str`) связан с ключом данных (`strength`) и русским названием.
- Добавлена нормализация старых и новых ключей расовых бонусов. Старые сохранения с `strength`/`wisdom` продолжают читаться.
- Расовые бонусы теперь объединяются с бонусами подрасы.
- Поддержаны выборы характеристик из `abilityBonusChoices` (в текущих данных это выбор двух разных характеристик полуэльфом, кроме Харизмы).
- Для альтернативного человека сохранены два выбора +1; проверка исходного файла показала, что оба выбора уже сохранялись. Аудит в этой части был неточным.
- Итоговая сводка мастера показывает характеристики с расовыми и подрасовыми бонусами.
- Карточка персонажа использует итоговые характеристики для отображения, инициативы и модификатора Мудрости.
- Добавлены unit-тесты нормализации ключей и итоговых характеристик.

## Проверки

- Проверена структура `races.json`: драконорождённый, подрасы дварфа и выборы полуэльфа.
- Выполнены статические проверки исходников и JSON: `STATIC_CHECKS_OK`.
- `flutter analyze` и `flutter test` не запускались: Flutter/Dart SDK отсутствует в рабочей среде.

## Важно

Навыки, пассивное Восприятие, кость хитов, сохранение файла и остальные пункты аудита в этом этапе не менялись.
